\noindent\emph{Data usage note.} Table~\ref{tbl-country-series-coverage} uses the raw cleaned WID file and is not screened. The plotted series use the analysis sample in \texttt{scg\_data.csv}, which keeps observations with non-missing capital and at least one of savings or consumption, but the plots themselves are currently unscreened. All figures now use the same plotted object: yearly GDP-weighted means, with LOESS fit to those yearly means. Table~\ref{tbl-5} applies the ratio screen $|g(K)| > 0.01$, while Table~\ref{tbl-indicator_table} applies the change-based screen $|\Delta g(K)| > 0.01$. Thus the paper now uses three distinct objects: raw cleaned coverage for Table~2, the unscreened analysis sample for the figures, and the screened analysis sample for Tables~3 and~4.
